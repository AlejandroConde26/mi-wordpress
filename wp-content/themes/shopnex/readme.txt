== Description ==
A modern WooCommerce theme for fashion stores, clothing brands, and lifestyle boutiques. Features responsive design, customizer options, blog support, custom widgets, and performance optimized for fast loading.

== Frequently Asked Questions ==

= Installation =
	
1. In your admin panel, go to Appearance -> Themes and click the 'Add New' button.
2. Type in 'shopnex' in the search form and press the 'Enter' key on your keyboard.
3. Click on 'Install' button to install and 'Activate' button to use.

= Where can I find the documentation of this theme?

1. Go to https://www.spiraclethemes.com/shopnex-documentation/
